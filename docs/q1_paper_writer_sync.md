# 第一问论文手同步文档

> 当前状态：第一问已完成可复现求解、结果表、布局坐标、布局图和校验文件。本文档只指导 Q1 写作，不替代 Q2-Q4。

## 1. 给论文手的总判断

第一问是无固定芯片轮廓、无连线关系的矩形模块非重叠装箱问题。题面给出的目标具有明显优先级：首先使外接轮廓面积最小；只有当轮廓面积相同，才比较长宽比是否更接近 1。因此正文要把目标写成词典序优化，而不是把面积和长宽比随意加权。

本次程序输出的是经过校验的可行布局上界，不是大规模实例的严格全局最优证明。严谨写法应为：“以所有模块总面积为理论下界，本文采用整数短边宽度枚举与矩形装箱算法搜索可行布局，得到三组芯片的当前最优可行解；所有结果均通过不重叠、面积守恒和外接轮廓计算校验。”不要写“证明得到全局最优”，除非后续补充精确算法证明。

## 2. 术语与符号统一表

| 术语/符号 | 建议全文统一写法 | 含义 |
|---|---|---|
| HardBlock | 硬模块 | `.blocks` 中类型为 `block` 的待摆放矩形 |
| Terminal | 固定端口 | 第一问不参与布局和面积约束 |
| `w_i, h_i` | 模块尺寸 | 第 `i` 个模块旋转后的宽和高 |
| `(x_i, y_i)` | 左下角坐标 | 第 `i` 个模块在布局中的位置 |
| `W, H` | 外接轮廓宽、高 | 所有模块外接矩形尺寸 |
| `A_block` | 模块总面积 | `sum_i w_i h_i`，是轮廓面积理论下界 |
| `A_box` | 外接轮廓面积 | `W H` |
| `rho` | 长宽比 | `max(W,H)/min(W,H)`，越接近 1 越方正 |
| `eta` | 面积冗余率 | `(A_box - A_block)/A_block` |

## 3. 第一问的问题分析怎么写

建议分三段：

第一段写任务抽象。说明第一问忽略连线关系和固定芯片边界，只需要决定每个硬模块的旋转方向和二维坐标。Terminal 在第一问不参与，因为题目只要求根据 `.blocks` 文件中类型为 `block` 的模块完成摆放。

第二段写目标优先级。面积目标是主目标，长宽比是同面积下的次级目标。为了避免人为设定面积与长宽比之间的权重，本文采用词典序目标：先比较外接面积，再比较长宽比偏离程度。

第三段写求解难点。矩形非重叠装箱是组合优化问题，随着模块数达到 100、200、300，精确枚举所有排列和旋转不可行。因此本文选择“理论下界 + 确定性宽度枚举 + 成熟装箱启发式 + 可行性校验”的路线。

## 4. 模型建立部分应写的公式

### 4.1 决策变量

对每个模块 `i`：

```text
r_i in {0,1}
```

其中 `r_i=0` 表示保持原方向，`r_i=1` 表示旋转 90 度。旋转后的尺寸为：

```text
(w_i(r_i), h_i(r_i)) =
  (w_i^0, h_i^0), if r_i = 0
  (h_i^0, w_i^0), if r_i = 1
```

坐标变量为：

```text
(x_i, y_i), x_i >= 0, y_i >= 0
```

### 4.2 非重叠约束

对任意两个不同模块 `i,j`，必须满足四个相对位置之一：

```text
x_i + w_i <= x_j
or x_j + w_j <= x_i
or y_i + h_i <= y_j
or y_j + h_j <= y_i
```

论文里要解释：这是矩形不相交的充要条件之一，程序验证时逐对检查该条件。

### 4.3 外接轮廓

```text
W = max_i (x_i + w_i)
H = max_i (y_i + h_i)
A_box = W H
rho = max(W,H) / min(W,H)
```

模块总面积：

```text
A_block = sum_i w_i^0 h_i^0
```

无论如何摆放，`A_box >= A_block`。这是第一问最重要的下界。

### 4.4 词典序目标

正式目标写成：

```text
min ( A_box, rho )
```

这里括号表示词典序比较，即先比较 `A_box`，只有面积相同才比较 `rho`。

程序中为了让启发式算法统一比较候选解，使用等价的整数主导代价：

```text
F = A_box + |W-H| / max(W,H)
```

因为 `A_box` 是整数，而后一项位于 `[0,1)`，所以任意 1 个单位面积的差异都会优先于长宽比差异；只有面积相同，后一项才起作用。这个设计不是人为权重，而是由整数面积粒度推导出的词典序实现。

## 5. 算法部分怎么写

### 5.1 候选模型比较

| 方案 | 内容 | 优点 | 局限 | 本文处理 |
|---|---|---|---|---|
| A 基线 | 按面积或边长排序后做 shelf/skyline 装箱 | 简单、可复现 | 易受排序影响，可能留下空洞 | 作为保底和对照 |
| B 主方案 | 整数短边宽度枚举 + skyline/MaxRects 装箱 | 无宽度步长，能系统搜索不同轮廓宽度 | 启发式放置不能证明全局最优 | 作为第一问主求解器 |
| C 精确模型 | MILP/CP-SAT 描述所有相对位置 | 可给最优性 gap | n100-n300 规模下变量和 Big-M 约束过大 | 可用于 Q4 或小实例验证，不作为大实例主解 |

### 5.2 宽度枚举为什么不是拍脑袋步长

程序只枚举整数宽度，没有使用 5、10、20 这类人为步长。理由如下：

1. 附件中模块尺寸均为整数，旋转后坐标由整数矩形装箱产生，因此候选外接宽度可按整数枚举。
2. 对任意布局，如果 `W > H`，整体旋转 90 度后面积不变，长宽比不变，且有新宽度 `H <= sqrt(A_box)`。因此只需要搜索不超过当前最优面积平方根的短边宽度。
3. 搜索过程中一旦找到更小面积，`sqrt(A_box)` 上界随之收紧，后续不可能通过更大的短边宽度得到更小面积。

### 5.3 程序流程

论文中可配一张流程图，建议标题为“第一问无固定轮廓布局优化流程”：

```text
读取 .blocks
  -> 提取 HardBlock 尺寸并计算 A_block
  -> 建立竖向堆叠初始可行解
  -> 由当前最优面积确定短边宽度搜索上界
  -> 对每个整数候选宽度 W_s：
       按多种确定性规则排序模块
       使用 skyline/MaxRects 放置模块并允许旋转
       计算外接面积和长宽比
       用词典序目标更新当前最优
  -> 输出布局坐标、面积、长宽比、可视化
  -> 独立校验面积守恒和两两不重叠
```

### 5.4 复杂度怎么写

设模块数为 `n`，候选短边宽度数为 `K`，排序规则/装箱算法数为 `S`。Skyline 每次放置需要扫描当前轮廓节点，节点数不超过 `O(n)`，所以单次装箱复杂度可写为 `O(n^2)`，总复杂度为：

```text
O(K S n^2)
```

MaxRects 增强器的最坏复杂度也可按 `O(K S n^2)` 量级描述，但常数更大。n300 上 MaxRects 增强耗时过高，因此本次 n300 使用 skyline 全整数宽度扫描结果。

## 8. 验证部分必须写

第一问至少写四项验证：

1. 面积下界验证：`A_block` 是任何布局都无法低于的理论下界。
2. 面积守恒验证：程序输出所有模块面积之和等于 `.blocks` 中模块总面积。

4. 结果边界验证：由于 n100-n300 是大规模组合优化，当前结果是启发式可行上界，不能宣称全局最优。

## 11. 复现命令

完整运行三组数据。脚本默认对 n100/n200 启用 `rectpack` 增强，对超过 200 个模块的 n300 自动回退到 skyline 全整数宽度扫描，以避免增强器耗时过长：

```powershell
python src/q1_floorplanning.py --data-dir "2026年第七届华数杯数学建模竞赛赛题\B题 VLSI布图规划设计\附件" --output-dir results\q1
```

n300 若增强器耗时过长，可使用 skyline 保底版本：

```powershell
python src/q1_floorplanning.py --data-dir "2026年第七届华数杯数学建模竞赛赛题\B题 VLSI布图规划设计\附件" --output-dir results\q1_n300_skyline --chips n300 --no-rectpack
```

如果后续需要强行对 n300 也启用 `rectpack`，可设置 `--rectpack-max-blocks 300`，但本轮测试中该设置耗时过长，暂不作为主复现路径。
