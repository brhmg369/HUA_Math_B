# LaTeX 论文骨架

本目录依据工作区根目录的 `format2024.doc` 和华数杯中文 LaTeX 模板建立。

编译命令：

```powershell
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex
```

格式约束：

- A4 纸，上下左右页边距均为 2.5 cm；
- 电子版从摘要专用页开始，摘要页页码为 1；
- 摘要、标题和关键词合计不超过一页；
- 第二页开始正文，正文不设置目录；
- 正文尽量控制在 20 页以内，参考文献之后为附录；
- 电子版不得包含承诺书和编号专用页；
- 论文与附录不得出现参赛者身份、学校或赛区信息。
